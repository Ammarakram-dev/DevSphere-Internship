## Linear Regression

> `DATA → FEATURES → TRAIN → PREDICT → EVALUATE → SAVE`

Week 3 introduced supervised machine learning through a regression workflow. The project uses the Student Performance Mathematics dataset to predict the final grade `G3` using previous grades `G1` and `G2`.

### 🎯 Objective

Develop and evaluate a Linear Regression model that predicts final student grades from previous academic performance.


# ⚙️ WEEK 06 — Breast Cancer Diagnostic Prediction System

> `DATA → PREPROCESSING → TRAINING → EVALUATION → PREDICTION`

Week 6 applies machine learning to a binary classification problem using the Breast Cancer Wisconsin dataset available through Scikit-learn.

The system compares classification algorithms, evaluates their performance, tunes a Logistic Regression model, and provides an interactive Streamlit interface for educational predictions.

### 🎯 Project Objectives

- Prepare and validate the dataset for machine learning.
- Train and compare Logistic Regression and Random Forest models.
- Tune model parameters using cross-validation.
- Evaluate predictions using classification metrics and visualizations.
- Save the trained model for reuse.
- Provide a user-input prediction interface.

### 🧠 ML Workflow

```text
📊 BREAST CANCER DATASET
          ↓
🧹 DATA VALIDATION & PREPROCESSING
          ↓
✂️ TRAIN / TEST SPLIT
          ↓
🤖 LOGISTIC REGRESSION + RANDOM FOREST
          ↓
⚙️ HYPERPARAMETER TUNING
          ↓
📈 MODEL EVALUATION
          ↓
📊 CONFUSION MATRIX & ROC CURVE
          ↓
💾 MODEL PERSISTENCE
          ↓
🖥️ STREAMLIT PREDICTION INTERFACE
```

### ✨ Key Features

- Dataset exploration and preprocessing
- StandardScaler and Logistic Regression pipeline
- Random Forest classification
- Model comparison using classification metrics
- GridSearchCV hyperparameter tuning
- Accuracy, precision, recall, F1-score, and ROC-AUC evaluation
- Confusion matrix and ROC curve visualizations
- Saved model for subsequent predictions
- Interactive Streamlit application

### 📊 Evaluation Visualizations

The project includes three visual outputs:

| Visualization | Purpose |
|---|---|
| Model Comparison | Compare the evaluated classification models |
| Confusion Matrix | Examine correct and incorrect class predictions |
| ROC Curve | Assess discrimination between the two classes |
